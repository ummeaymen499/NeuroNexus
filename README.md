# 🌐 Internship Selection Task - Google Form Clone (HTML & CSS Only)

This project is a **Google Form-like web form**, created using only **HTML and CSS**, as part of my internship selection task.

## ✅ Features

- Clean and professional layout
- Collects the following details:
  - Full Name
  - Contact Number
  - Address
  - Company Name
  - Email Address
  - Department (HR, Sales, Development, Marketing, Others)
  - Gender (Male, Female, Prefer not to say)
- Fully responsive design
- No JavaScript used — purely HTML5 & CSS3

## 🌟 Bonus Highlights (Optional Features Implemented)

- 🎨 **Stylish Design**  
  A modern and minimal UI with:
  - White form card on a soft grey page background
  - Floating labels for a sleek user experience
  - Subtle box-shadow to elevate the form

- 🖱️ **Hover Effect on Submit Button**  
  Smooth hover animation with shadow and scale effect for better interactivity

- 🌈 **Gradient Heading**  
  A unique touch to the form’s title using a linear gradient text style
